Personal Portfolio Website
    A modern and responsive personal portfolio website built using HTML, CSS, JavaScript, and Bootstrap to showcase skills, projects, and contact information.

Features
  - Responsive Design: Looks great on mobile, tablet, and desktop devices
  - Smooth Scrolling: Easy navigation between sections
  - Interactive Elements: Buttons, modals, and project cards with hover effects
  - Project Showcase: Highlight your projects with images, descriptions, and links
  - Contact Form: Integrated contact form to reach you directly
  - Clean UI: Modern and professional design using Bootstrap 5

Technologies Used
  - Frontend: HTML5, CSS3, JavaScript (ES6), Bootstrap 5
  - Design & UI: Flexbox, Grid, CSS animations, responsive layouts
